# Login and Sign-Up Form

A simple web-based Login and Sign-Up Form UI created using HTML and CSS. This project demonstrates basic form design, input fields, CSS styling, and navigation between login and registration pages.

## Features

* Login form with email/phone and password fields
* Sign-up form with personal information fields
* Gender selection using radio buttons
* Date of birth and mobile number fields
* Email and password confirmation fields
* Terms and Conditions checkbox
* Blue-to-purple gradient background
* Navigation between Login and Sign-Up pages
* Simple and clean form layout

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
login-signup-form/
├── index.html
├── SignUp.html
└── README.md
```

## How to Run

1. Clone or download this repository.
2. Keep `index.html` and `SignUp.html` in the same folder.
3. Open `index.html` in your web browser.
4. Click the Sign Up link to open the registration form.
5. Use the Log In link to return to the login page.
